# Secure Offline Digital Payment System

## Description
This project implements a secure offline payment system using QR codes.

## Features
- QR based payments
- Offline transaction verification
- Double spending prevention
- SQLite ledger

## Technologies
- Python
- OpenCV
- Pyzbar
- SQLite
- Tkinter

## Run the Project
pip install qrcode opencv-python pyzbar

python gui_main.py
